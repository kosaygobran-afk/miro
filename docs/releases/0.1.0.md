# MIRO 0.1.0 — console and storefront redesign

Release date: 2026-10-02. Source branch: `0.1.0`. Merge target: `main`.

This release makes the CEO/admin console cohesive across its routed workspaces and improves the customer storefront while preserving its established three themes. It also connects the new design controls to the database, public store refresh and owned media storage. Package and lockfile versions are `0.1.0`; Next.js remains pinned to `16.3.8`.

## CEO and admin interface

- Applied the premium charcoal/blue, gold, cyan, violet and lime management design to navigation, topbar, Overview, Requests, Finance, Analytics, Products, New Product, Product Editor, Categories, Services, Inventory, Suppliers, Sales/history, Customers/details, Users, Audit, Settings and Store Merchandising.
- Added a searchable page finder, persisted comfortable/compact density, clearer page hierarchy, real related-workspace links, scoped collection summaries, filters and compact named icon controls. Supplier company headers/cells are centered. Long display values move only when clipped; typed inputs stay still and reduced-motion values wrap.
- Requests supports table/board views, advanced filters, assigned-to-me, details and failed-assignment recovery. Finance adds period comparisons, selectable charts and daily ledger. Analytics adds overview/product views, rankings and details linked to actual products. All-time date choices now request their actual API ranges.
- Shared dialogs/drawers suspend background interaction, manage nested overlays and restore focus. Sales drafts survive switching views. Overview links seed validated filters and use Israel-calendar reporting boundaries. Audit filters/details retain their original authorization and metadata boundaries.

## Customer storefront and design studio

- Retained dark/medium/light public themes with refined navigation, typography, icons, category cards, product cards, galleries, image containment, RTL arrows and stable 3D hover previews. Preview intent defaults to 200 ms; moving rails pause during preview interaction and close correctly on Escape.
- Added equal-size IBM, TP-Link, Ubiquiti, Hikvision, Ajax, Seagate, Western Digital and Dahua identifiers below categories, with pause/reduced-motion support. Five original generic technology backgrounds rotate every ten seconds by default.
- Added `/[locale]/admin/store-design`: CEO edits, uploads, reorders, hides/removes brands/backgrounds and controls timing, transition style, product speed and hover delay. Admin can view only. Publish saves a validated, actor-audited revision and updates another already-open anonymous storefront. Discard changes and Reload recover stale drafts explicitly.
- Uploads enforce active CEO, same origin, 5 MB image bounds, byte/extension agreement and SVG sanitization. Public design and inventory-default reads expose only dedicated projections; private settings are not public. Stale application revisions use `PT409` so hosted PostgREST returns prompt HTTP 409 rather than retrying a serialization error until timeout.
- Hamburger navigation floats above hero imagery as a document-positioned portal with no separate scroll container. Account popups portal above it, remain inside phone gutters, support arrow/Home/End navigation and restore focus. Both have deep 96% theme glass surfaces, real blur and opaque text during entrance. Authenticated header controls fit 320px phones.
- Product cards gain shared-cart +/− controls after the first addition, synced header count, persistence and removal at zero. Clipped display titles animate; editable fields stay static. Product media failures use original SVG fallbacks.

## Catalog, database and assets

- Added 40 manufacturer-referenced models, five per category across eight active categories, preserving existing entries. References have no selling price or confirmed stock and are quote-only. Source metadata, bilingual descriptions and internal non-GTIN barcodes distinguish them from approved inventory.
- Added 30 original device SVG illustrations, three views per visual kind; 120 reference-product image rows use durable owned storage URLs. The missing hosted `product-media` bucket was provisioned with the documented public/image-only/5 MB configuration. All 30 URLs returned actual SVG artwork. Import/publication scripts default to dry run and preserve matching products and owner-uploaded media.
- Applied `20261002010000_storefront_design.sql`, `20261002020000_public_inventory_defaults.sql` and `20261002030000_storefront_design_conflicts.sql`. New public settings changes use the existing catalog-version Realtime/poll/focus refresh signal. Older applied migrations were not rewritten.
- Bounded server Supabase requests settle unavailable upstreams, missing management configuration returns an explicit 503, and the sitemap reads the catalog anonymously without the former static-build fallback warning.
- Updated AGENTS, design system, routes/roles, operations, project status and the customer operating guide. Included the historical September 28 audit/implementation brief and its baseline evidence; those findings describe that earlier baseline rather than current unresolved status.
- Generated background prompts/tool mode and brand provenance are recorded in `public/images/store-design/generation-notes.json` and `docs/CUSTOMER_DESIGN.md`. Decorative backgrounds and device illustrations are not manufacturer product photography or evidence of a commercial partnership.
