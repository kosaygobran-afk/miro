# MIRO 0.1.6

Source branch `0.1.6` merges into `main`. The package and lockfile are both version `0.1.6`.

## Changes

- Updated the storefront navbar with gold hover and current-page emphasis, frameless utilities, a bordered search field, and a cleaner Store category dropdown. Headline spacing provides separation on desktop and phones.
- Added public product suggestions in English and Hebrew with up to five results per page. Search matches product names, brand, model, slug, SKU and barcode. Results open the storefront product page and follow public catalog visibility rules.
- Restored the original CEO and admin navbar and workspace finder. The topbar background matches the management shell in each theme.
- Aligned the collection intro to the left in both locales while preserving text direction. Kept the selected category chip visible during resizing and gave desktop filters and search separate rows.
- Included the verified Next.js 16.4.6 security upgrade. [Project status and earlier verification](../PROJECT_STATUS.md)

## Verification

- Lint, TypeScript, all 483 unit tests, and the isolated production build with 152 prerender tasks passed.
- Read-only production smoke checks found the live barcode match and two distinct pages of public search results in English and Hebrew. The management navbar was checked with disposable CEO and admin accounts in both languages and all three themes. [Browser evidence and follow-ups](../PROJECT_STATUS.md)
